# GUMP 操作對照與 Kino Pick UI 整合（2026-11-16）

## 使用者確認的主流程

邊看照片、邊挑與留意見，最後整本下載或複選下載。正式挑片／送出不是每份分享的必經流程。以 GUMP 作為圖庫、清單、燈箱、圖示及分享操作的對標，保留 Kino Pick 品牌、已接線功能與權限隔離。

## 本次實際研究

透過使用者指定的 Edge 分頁檢查相簿、圖片清單、單張燈箱及評論工具；沒有修改 GUMP 照片、收藏、推薦、置頂或分享設定。

- 實測瀏覽模式切換加入 `aiv=list`；進入照片與返回圖庫時保留排序、瀏覽模式及照片定位參數。
- 讀取已載入頁面的 DOM、公開 CSS 與前端 JavaScript。圖庫 chunk `3ucvv5x4s32a3.js` 有模式切換與 Muuri 相關程式，燈箱 chunk `1u0w864mgi3dr.js` 有左側工具及照片舞台。CSS `3u71y05lu6smx.css` 證實左欄以 hover／active 展寬，照片區另行分配空間。
- 原始 HTML 的獨立匿名 HTTP 讀取遇到重新導向迴圈；未繞過登入，研究依 Edge 已顯示 DOM 與公開資源。未取得或推定其伺服器程式。
- Edge 現有 session 同時露出攝影師操作，不能把這一份畫面當成純匿名客戶權限驗收。狀態位置必須分角色與模式記錄。

## 本機已實作

- 共用深色燈箱、左側圖示／展開工具、無文字關閉、低對比換頁箭頭。
- 檔案資訊、標籤、留言與繪圖等沿原元件收在 native disclosure，空的未授權工具不出現。版本比較保留自己的展開／關閉與既有滿版規則。
- 預覽縮放 100／150／200%，按照片循環、加減及重設；換照片／版本重新初始化。百分比以預覽適合視窗為基準，不代表原始相機檔像素。
- 縮圖列底部漸隱；展開時實際增加 grid row 高度、縮小照片舞台，沒有蓋住照片。
- 分享 QR 只在新建立且一次性連結仍可取得時產生；舊連結 token 無法由雜湊重建，沒有新增長期憑證保存。
- 補上最新 main 遺漏的 workspace helper、content-count hook import，以及 ZIP Uint8Array 的 ArrayBuffer 型別。
