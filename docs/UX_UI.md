# UI/UX 規格

## 品牌方向

攝影作品是主體，UI 以中性灰/暖白/炭黑、充足留白、低干擾層級為主；輔助狀態使用小面積色彩，不使用大面積漸層或浮誇裝飾。繁中優先。桌面主欄寬 1280-1440px，RWD 手機至小於 375px。

## A. 攝影師後台 IA

`Dashboard` `專案` `客戶` `儲存與清理` `通知` `設定/品牌`。

- Dashboard：進行中與即將過期專案、候選清理空間、最近留言、待挑片/待確認。
- Project detail tabs：`照片` `挑片結果` `修圖版本` `留言與標註` `歷史紀錄` `成品交付` `設定`。
- Photos：拖放上傳、批次進度、version match 面板、批次選取/標記、上傳失敗重試。
- Storage：用量指示（原圖/版本/縮圖/暫存）、提示「Soft quota 非 Cloudflare 硬上限」、80% 和 30 天政策開關、最舊相簿候選清單、dry-run 確認、保護/釘選、最近清理報告。

## B. 客戶網格（Grid）

桌面 4–6 columns，平板 2–4，手機 2。圖片本身維持比例；使用 Lazy Loading、逐頁載入，避免 1000 張照片 DOM 一次渲染。顯示 photo filename（可關）、序號、星等/收藏/選取與有留言小標。工具列：全部／已選／未選／收藏／星等／標籤／有註記；排序：拍攝時間／檔名／上傳順序。

點照片開啟 Lightbox；選取可使用 checkbox，不與進入大圖混淆。桌面支援 Ctrl/Cmd additive select、Shift range select、鍵盤 1–5 星；手機靠點選。底部固定選片計數條（例如 已選 18/30），有明確「送出挑片」二次確認。

## C. Lightbox

桌面：大圖中央偏左，右側面板 `留言`、`標註`、`版本`、`活動紀錄`；頂部照片名／切換；底部 favorite / rating / select。手機：滿版照片、底部 sheet 分頁。不載入原始 100MB 檔到 Grid。

## D. Annotation

點「標註」後可畫矩形／箭頭／點選標示（MVP 支援矩形/點即可），連結一則留言。使用 0..1 相對座標，縮放正確回放；尊重 EXIF orientation；可切換顯示/隱藏註記；狀態 open/resolved/reopened。

## E. 版本差異

版本下拉選擇 Before 與 After；三種切換：`滑桿` `左右並排` `疊合`。手機滑桿支援手勢，桌面支援鍵盤。P2 `差異熱區` 須顯示「數值僅表示像素變化，不代表修圖品質」，並標示尺度不合時不可比較。

## F. 客戶歷程

我的選片、我留的意見、照片活動歷程，時間格式支援本地時間顯示但 API UTC 儲存。保留「已選→取消→再選」逐筆記錄。跨專案活動入口只有額外 OTP/portal token 之後才顯示有授權的歷史專案。

## G. 空狀態與錯誤

- 邀請失效：明確顯示「連結已過期/已撤銷」並提示聯絡攝影師，不透露專案資料。
- 上傳接近容量：顯示何時需要釋放空間，禁止暗中刪使用者資料。
- 30天過期：有可自訂通知文字，業主與有聯絡方式的客戶按 policy 預告。
- 權限不足：按權限隱藏不可用操作，同時 server 一律驗權限。
- 歷史照片已刪除：保留文字事件與可識別檔名 tombstone（符合保留與隱私設定），不要破圖或暴露 R2 key。

## H. Accessibility

可聚焦 control、鍵盤相簿操作、圖片描述可選、按鍵可操作 slider、對比度足夠、ARIA live region 更新已選數、視覺狀態不能只有顏色、避免對長時間 grid 操作造成滾動跳動。
