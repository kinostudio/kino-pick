# Ponytail：本次 UI／權限修正審查

本次把未完成的「讀取」與真正待確認的「寫入」分開，補回固定工作區的處理設定路由，並精簡設定與歷史介面。沿用既有元件、journal、Owner服務、快照、匯出及原生表單，沒有新套件、schema或另一套前端。

審查範圍包含實際呼叫端、服務查詢及測試。以每頁最多24筆、操作者最多3類為界；多選條件在授權SQL內以參數化IN查詢，空選擇為零結果，快照／cursor／匯出共用固定順序條件。未把整個租戶資料抓到瀏覽器再過濾。既有單一actorType仍接受，衝突、重複及超量條件拒絕。

檢查過的風險：不靠解除全部導航鎖修復燈箱，不刪journal；讀取404可離開，但真草稿／不確定寫入仍鎖定並沿用同UUID復原。B只加固定workspace的GET／POST，沒有新增通用workspace路由或略過Owner／Origin／session。設定頁的Oracle儲存和縮圖處理是不同功能，未假稱VM縮圖已接通。

精簡結果：重用SVG、原生radio／checkbox／details及既有版面按鈕，刪除設定頁重複側欄占位；先讀到必要資訊，版本與來源資料按需展開。沒有為UI新增資料庫或持久狀態層。

本機結論：通過集中原生、單元、strict、lint／build驗證，可送既有CI。仍須CI通過及B真實頁驗收後才稱上線。完整產品MVP、30GB滿載與Oracle重開機驗收不在本次範圍。
